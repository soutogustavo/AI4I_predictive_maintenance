# Data

This directory should contain the raw dataset for the predictive maintenance challenge, `ai4i2020.csv`.

You can download it from [UCI](https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset), and place it in this folder.

In Production, the data would be streamed from a data source, such as a database, a message queue, or a data lake. In this case, we use a CSV file as a mock data source.
