
# Remarks

- Data is clean, no missing values. Therefore, it does not present noisy I used
to deal with at Proemion.

- 339 failures in 10.000 records, or less than 3,4% of the data. This is an
extremely unbalanced class problem. Precision, recall, F1, and mainly PR-AUC
(not ROC-AUC) are the right metrics here.

- Tabular data with well-defined numerical and categorical features is
exactly where gradient boosting shines.
